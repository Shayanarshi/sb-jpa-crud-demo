# Spring Data JPA CRUD

A Spring Boot application demonstrating CRUD operations using **Spring Data JPA**.

## 🚀 Technologies

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven
- SQL

## 📌 Features

- Create employee records
- Retrieve employee records
- Update employee records
- Delete employee records
- Database integration using Spring Data JPA
- Repository-based data access

## 🎯 Purpose

This project was created to practice **Spring Data JPA, CRUD operations, entity mapping, repository interfaces, and database integration** with Spring Boot.
